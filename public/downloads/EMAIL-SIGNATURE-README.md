# Outlook email signature — Justin Van Staden / Golden Tide

File: `email-signature-outlook.html`  
Email on signature: **justin@goldentide.cloud**

## Install in classic Outlook (Windows)

1. Open `email-signature-outlook.html` in Chrome or Edge.
2. Select the signature block (name through tagline) and copy (`Ctrl+C`).
3. Outlook → **File** → **Options** → **Mail** → **Signatures…**
4. **New** → name it `Golden Tide` → paste into the editor → **OK**.
5. Set it as the default for new messages and replies.

## Install in Outlook on the web / new Outlook

1. Open the HTML file in a browser and copy the signature.
2. Settings → **Account** → **Signatures** → create new → paste → Save.

## Tip

If formatting breaks on paste, paste into Word first, then copy from Word into Outlook.
