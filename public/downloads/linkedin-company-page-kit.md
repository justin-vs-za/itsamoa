# LinkedIn Company Page — Golden Tide (itsamoa.goldentide.cloud)

You are already logged into LinkedIn on **your** computer. Create the page there using the copy below (this agent cannot access your LinkedIn login).

## Create the page (≈5 minutes)

1. Open LinkedIn while signed in: https://www.linkedin.com/
2. Go to: **https://www.linkedin.com/company/setup/new/**
   - Or: **Me** (top right) → **Create a Company Page** → **Company**
3. Fill the form with the values in **Page details** below.
4. Tick LinkedIn’s terms → **Create page**.
5. Complete **About**, logo, cover, and website URL using the sections below.
6. Click **Start posting** / **Build page** and publish the first post (optional starter below).

> LinkedIn may ask you to verify with a work email. Use **justin@goldentide.cloud** if prompted.
